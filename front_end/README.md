# Front End

One-line startup:

```powershell
python -m streamlit run front_end/app.py
```

Main pages:

- `Home`: random benchmark query, manual query, method selection, and parameter control
- `Search Results`: GT rank for benchmark queries, top-5 playable videos, and manual-query feedback
- `History`: latest 10 searches with jump-to-result
- `Learning Logs`: auto-learning logs, diary, and user feedback queue
- `Ablations`: summary table, metric curves, candidate recall, and failure diagnosis
