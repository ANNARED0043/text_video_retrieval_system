### 中文摘要建议替换稿

```text
随着在线视频内容规模持续增长，用户越来越希望直接通过自然语言描述目标内容，并从大规模视频库中检索出语义匹配的视频。现有文本到视频检索方法通常依赖视觉语言预训练模型，将文本查询与视频内容映射到同一语义空间，再通过向量相似度完成候选召回。该范式具有较高检索效率，但在复杂自然语言查询下仍存在明显不足：当多个候选视频在场景、人物或动作上整体相似时，模型容易召回相关视频，却未必能够将真正匹配查询细节的目标视频排在首位。

针对上述问题，本文设计并实现了一个基于自然语言查询的视频检索系统。系统以 MSR-VTT 数据集为实验基础，首先对视频进行片段化处理，利用预训练视觉语言模型提取视频与文本特征，并基于 FAISS 构建向量索引，实现高效候选召回。在此基础上，本文实现了选择性查询改写与候选重排序模块，用于分析大语言模型在查询语义补充和候选语义校准中的辅助作用。实验表明，这类流程型增强能够改善部分查询，但其整体收益受到候选质量、调用成本和语义漂移等因素限制。

进一步地，本文将研究重点放在跨模态表示空间的细粒度对齐增强上，提出 alignment teacher 与 multiview features 相结合的表征增强方法。该方法利用 alignment teacher 提供局部动作、对象、场景和关系等语义监督，并通过多视角视频特征补充不同时间片段中的局部视觉证据，使学生检索模型不仅学习整句查询与整段视频之间的全局相似度，还学习查询语义成分与视频局部证据之间的对应关系。实验结果表明，在 locked 1kA 协议的快速验证设置下，该方法相较基础检索模型取得了更优的 R@1 表现，说明细粒度表征增强能够有效改善自然语言视频检索中的首位排序校准问题。

本文还探索了错误驱动反馈学习机制，通过 failure diagnosis、feedback teacher 和 acceptance-gated promotion 对检索失败样本进行筛选和反馈学习。实验结果显示，该闭环在安全验证集上具有一定正向效果，但在 locked 1kA 协议下尚未稳定超过当前最佳细粒度增强模型。总体而言，本文工作表明，自然语言视频检索系统的性能提升不仅依赖查询改写和重排序等流程型模块，更关键的是提升文本语义成分与视频局部证据之间的细粒度对齐能力。
```

### 1.3 本文主要研究内容与创新点（整节替换）

```text
本文围绕基于自然语言查询的视频检索系统设计与实现展开研究，目标是在保证系统可运行、可评估和可展示的前提下，进一步改善复杂查询场景下的首位排序能力。全文主要研究内容如下。

第一，构建自然语言视频检索 baseline 系统。本文以 MSR-VTT 数据集为实验基础，对原始视频进行片段化组织，利用预训练视觉语言模型提取文本与视频特征，并通过 FAISS 构建向量索引，实现文本查询到候选视频的高效召回。该部分为后续查询改写、候选重排序、细粒度表征增强和系统展示提供统一实验底座。

第二，设计查询理解增强与候选优化模块。针对自然语言查询中可能存在的表达省略、语义含混和候选排序偏差问题，本文实现了选择性查询改写和候选重排序流程。选择性查询改写通过歧义检测判断是否需要调用大语言模型进行语义补充，候选重排序则在初始召回结果基础上进一步比较查询语义与候选视频内容的一致性。实验结果表明，该类模块能够提升部分查询的检索效果，但其收益具有明显场景依赖性。

第三，提出 alignment teacher 与 multiview features 相结合的细粒度表征增强方法。这是本文的核心方法贡献。针对双塔检索模型在对象、动作、人物属性和关系语义上容易发生局部混淆的问题，本文引入 alignment teacher 作为局部语义监督来源，并结合多视角视频特征补充不同时间片段中的视觉证据。该方法使学生模型在保持高效向量检索结构的同时，学习查询语义成分与视频局部证据之间的对应关系，从而改善 Top-1 排序校准能力。

第四，探索错误驱动反馈学习闭环。本文在系统运行过程中记录检索失败样本，并尝试构建 feedback teacher、memory 机制和 acceptance-gated promotion 策略，使系统能够从错误样本中筛选高价值监督信号。该部分主要作为持续优化方向的探索，用于分析反馈学习在视频检索系统中的可行性和局限。

综上，本文的创新点主要体现在以下三个方面：（1）构建了一个覆盖数据处理、特征提取、向量索引、检索评估、前端展示和日志记录的自然语言视频检索系统；（2）提出以 alignment teacher 和 multiview features 为核心的细粒度表征增强方法，突出解决全局向量检索难以区分局部语义差异的问题；（3）从系统运行日志和失败样本出发，探索错误驱动反馈学习机制，为后续构建可持续优化的视频检索 agent 提供实验基础。
```

### 3.1 方法设计目标与总体框架（替换稿）

```text
本文方法设计的核心目标并不是单纯扩大候选召回范围，而是在高效召回基础上进一步提升目标视频的首位排序能力。对于文本到视频检索任务而言，基础双塔模型通常能够将查询与整体相关的视频映射到相近语义空间，但当多个候选视频具有相似场景或相似动作时，仅依赖全局向量相似度容易忽略对象、人物属性、动作顺序和局部关系等细节。因此，本文将检索流程划分为“候选召回”和“细粒度校准”两个层次：前者保证系统能够快速找到相关候选，后者通过局部语义监督和多视角视频表示改善候选内部排序。

本文整体框架如图3-1所示。系统首先对视频进行片段化处理，并利用预训练视觉语言模型提取视频特征；随后构建 FAISS 向量索引，实现文本查询到候选视频的初始召回。在系统增强层面，本文加入选择性查询改写和候选重排序，用于分析大语言模型对查询补充和候选判断的辅助作用。在核心方法层面，本文提出 alignment teacher 与 multiview features 相结合的细粒度表征增强方法，使学生模型能够学习查询语义成分与视频局部证据之间的对应关系。最后，本文进一步探索错误驱动反馈学习闭环，用于从失败样本中筛选高价值监督信号。
```

### 3.4 Alignment Teacher 引导的细粒度对齐学习（替换稿）

```text
在基础双塔检索结构中，文本查询和视频通常被压缩为单一全局向量，并通过余弦相似度计算匹配程度。该结构有利于构建高效向量索引，但在细粒度候选区分上存在天然不足。例如，两个候选视频可能都包含“人在厨房中操作”的整体场景，但只有其中一个视频真正满足“切菜”“倒水”或“戴眼镜的女性”等局部语义约束。为缓解这一问题，本文引入 alignment teacher，为学生检索模型提供局部语义对齐监督。

具体而言，本文将查询中的语义成分划分为动作、对象、场景和关系等类型，并结合教师模型对候选视频进行局部语义评估。设查询为 q，目标视频为 v+，候选负样本为 v-，学生模型给出的相似度函数为 S(q,v)。基础对比学习主要优化正负样本之间的整体相似度差异，而 alignment teacher 进一步提供局部语义层面的软监督，使模型不仅关注“视频是否整体相关”，还关注“视频中的局部证据是否满足查询中的关键成分”。

本文采用的教师监督可表示为：

L_teacher = KL(P_t(q,V) || P_s(q,V))        （3-1）

其中，V 表示候选视频集合，P_t(q,V) 为 teacher 根据局部语义证据生成的候选分布，P_s(q,V) 为 student 根据当前表示计算得到的候选分布。通过该损失，学生模型能够从 teacher 的候选偏好中学习更细粒度的排序信息。

为了进一步增强相似候选之间的区分能力，本文在训练中引入 pairwise 排序约束：

L_pair = max(0, m - S(q,v+) + S(q,v-))        （3-2）

其中，m 为间隔超参数。该损失要求目标视频的相似度高于相似负样本，尤其适用于目标视频已经进入候选集合但未排在首位的 near-miss 样本。该设计与细粒度视频文本对齐研究中强调的 hard negative 和 pairwise preference 思想一致，有助于提升模型对局部差异的敏感度。
```

### 3.5 Multiview Features 多视角视频表征增强（替换稿）

```text
视频与图像的显著区别在于其包含连续时间片段和动态事件过程。如果仅使用单一全局视频向量表示整段视频，模型容易忽略不同时间位置上的局部证据。为此，本文构建 multiview features，将视频表示为多个时间视角下的局部特征集合，从而为查询中的动作、对象和关系成分提供更丰富的视频侧证据。

设视频 v 被划分为 T 个时间视角，每个视角的特征表示为 h_i，则视频的多视角表示可写为：

H_v = {h_1, h_2, ..., h_T}        （3-3）

对于查询 q，模型首先计算查询表示 z_q 与每个时间视角之间的相似度，并取最大响应作为多视角匹配分数：

S_mv(q,v) = max_i cos(z_q, h_i),  i = 1,2,...,T        （3-4）

该设计的意义在于：当目标语义只出现在视频的局部片段中时，多视角表示能够避免局部证据在全局平均过程中被稀释。例如，对于“一个人先拿起杯子再喝水”的查询，关键证据可能只存在于视频中间或后段；若直接使用全局平均特征，动作细节可能被背景信息掩盖，而多视角特征能够保留不同时间片段中的局部响应。

最终，本文将全局匹配分数、alignment teacher 分数和多视角匹配分数进行联合建模：

S(q,v) = S_global(q,v) + λ_1 S_align(q,v) + λ_2 S_mv(q,v)        （3-5）

其中，S_global 表示基础全局相似度，S_align 表示 alignment teacher 提供的局部对齐得分，S_mv 表示多视角视频特征匹配得分，λ_1 和 λ_2 为权重系数。实验结果表明，单纯增加后处理重排序并不能稳定带来最优 R@1，而 alignment teacher 与 multiview features 通过改变学生模型表示本身，能够更直接地改善首位排序能力。
```

### 3.6 联合训练目标与方法消融分析（新增/替换稿）

```text
为统一建模基础检索、教师监督、多视角特征和排序约束，本文将学生模型训练目标写为：

L = L_rank + αL_teacher + βL_pair + γL_proto + δL_preserve        （3-6）

其中，L_rank 表示基础候选排序损失，L_teacher 表示 teacher 分布蒸馏损失，L_pair 表示正负样本 pairwise 排序约束，L_proto 表示原型语义约束，L_preserve 用于保持模型不过度偏离原始检索空间。该联合目标的设计原则是：在不破坏基础召回能力的前提下，使模型更关注相似候选之间的局部语义差异。

为了验证各模块的作用，本文设置了由浅到深的消融实验。实验结果显示，查询改写与重排序能够改善部分查询，但收益不稳定；相比之下，alignment teacher 和 multiview features 对 R@1 的提升更直接，说明本文主方法的增益主要来自学生检索表示本身的改善，而不是简单后处理分数融合。
```

### 4.1.2 系统模块划分（替换稿）

```text
本文系统按照数据流和功能边界划分为六个模块。

（1）数据预处理与清单构建模块。该模块负责读取 MSR-VTT 原始标注文件和视频路径信息，完成视频样本筛选、片段元数据组织、manifest 文件生成和查询子集构建。其目标是将原始视频和文本标注转换为统一、结构化、可索引的数据形式，为后续特征提取和检索评估提供稳定输入。

（2）视频特征提取与多视角表示模块。该模块负责对视频片段进行离线视觉编码，生成基础视频特征和多视角视频特征。基础特征用于构建向量索引，多视角特征用于补充不同时间片段中的局部视觉证据。离线特征提取能够降低在线检索计算开销，是系统高效运行的重要基础。

（3）向量索引与基线检索模块。该模块基于 FAISS 构建视频特征索引，将用户文本查询编码为文本向量后，在向量空间中检索相似视频，并通过视频级聚合策略生成初始排序结果。该模块是系统运行底座，也是后续增强模块的共同输入。

（4）查询理解增强与候选优化模块。该模块包括选择性查询改写和候选重排序两部分。选择性查询改写根据歧义检测结果判断是否调用大语言模型对查询进行语义补充；候选重排序则对初始 Top-K 候选进行进一步语义比较，用于提升部分复杂查询的排序质量。

（5）细粒度表征增强与教师监督模块。该模块是本文方法实现的核心，负责接入 alignment teacher、多视角视频特征和教师监督信号，引导学生检索模型学习文本语义成分与视频局部证据之间的对应关系。该模块的输出不是简单后处理分数，而是经过增强后的学生检索表示。

（6）前端交互与日志可视化模块。该模块负责提供可交互的视频检索页面，包括随机查询、手动查询、参数选择、检索结果展示、视频播放、历史记录、学习日志和消融结果展示等功能。通过该模块，系统不仅能够完成离线实验评估，也能够展示真实检索流程和用户交互结果。
```

### 11.1 第3章：基于细粒度对齐增强的自然语言视频检索方法

#### 3.1 方法设计目标与总体框架

##### 3.1.1 问题定义与任务设定

第一段写任务定义：给定自然语言查询 \(q\) 和视频库 \(\mathcal{V}\)，系统需要输出与查询语义最匹配的视频排序列表。这里只保留必要定义，不重复第2章关于检索任务的理论介绍。

第二段写本文任务难点：MSR-VTT 查询多数语义较短，但目标匹配常依赖动作、对象、人物属性和局部关系；全局向量能够召回整体相关候选，却容易在相似候选之间产生 Top-1 排序错误。

第三段写评价目标：本文不把研究目标写成单纯提升召回范围，而是写成“在高效候选召回基础上提升首位排序校准能力”。这样能自然引出 alignment teacher 与 multiview features。

##### 3.1.2 方法设计原则

第一段写效率原则：保留双塔检索和 FAISS 索引作为底座，避免把所有候选都交给高成本交叉编码器。

第二段写细粒度原则：在训练阶段引入局部对齐监督和多视角视频表示，使学生模型学到更接近检索瓶颈的局部语义判别能力。

第三段写安全评估原则：训练与反馈只使用 train 9k 安全子集和 safe_dev；locked 1kA 只用于最终报告，不参与训练和反馈学习，避免数据泄露。

##### 3.1.3 分层检索框架

第一段写三层结构：基础召回层、系统型候选优化层、细粒度表征增强层。基础召回层负责速度，候选优化层负责分析 rewrite/rerank 的辅助价值，表征增强层是本文主方法。

第二段放图3-1：图名“图3-1 本文自然语言视频检索方法总体框架”。插入位置为 3.1.3 第二段之后。已生成 draw.io 文件：`outputs/figures/Figure3-1_overall_framework.drawio`。

第三段解释图3-1：重点说明蓝色加粗区域是本文核心贡献；rewrite/rerank 是系统型辅助模块，不作为最终主增益来源。

##### 3.1.4 本文方法贡献定位

第一段明确创新点：本文提出“对齐教师监督与多视角视频特征融合的细粒度表征增强方法”，用于提升文本到视频检索中的候选内部排序能力。

第二段写区别：该方法不是简单后处理分数融合，而是通过训练学生检索模型改变其表示空间；实验中 best_method 为 adapter 而非 fused score，可以作为后文第5章的重要论据。

第三段写本章展开顺序：先讲基线召回，再讲 rewrite/rerank 的定位，随后重点讲 alignment teacher、multiview features、联合训练目标和消融实验设计。

#### 3.2 基线召回与视频级表示方法

##### 3.2.1 视频片段化与离线特征提取

第一段写视频片段化：将原始视频组织为片段级样本，生成 manifest，保证视频 ID、片段路径、时间位置与查询标注能够对应。

第二段写离线特征：使用 ViT-H-14 / LAION2B_S32B_B79K 提取片段特征，并离线保存，降低在线检索时间。

第三段写必要公式：给出片段特征 \(z_i=f_v(s_i)\)，视频由多个片段特征集合 \(\{z_i\}_{i=1}^{n}\) 表示。

##### 3.2.2 文本查询编码与相似度计算

第一段写文本编码：查询通过文本编码器得到向量 \(t=f_t(q)\)，并与视频片段或视频级表示计算余弦相似度。

第二段放公式：

\[
S(q,v)=\cos(t,\bar{z}_v)=\frac{t^\top \bar{z}_v}{\|t\|\|\bar{z}_v\|}
\]

说明该式是 baseline 的基础评分方式。

##### 3.2.3 视频级聚合策略

第一段写 mean pooling 与 max pooling 的区别：mean pooling 更稳定，max pooling 更强调局部显著片段但可能放大噪声。

第二段引用现有实验图：可在第5章详细展示 mean/max 对比；本节只说明本文采用 mean pooling 作为主设置的原因。

##### 3.2.4 基础候选召回的作用边界

第一段写 Top-K 候选召回的意义：如果目标视频未进入候选集合，后续重排序和反馈学习都无法修正。

第二段写本文定位：candidate recall 结果表明 Top-30 以后边际收益下降，因此后续核心问题转为“目标已在候选内但排序不够靠前”。

#### 3.3 查询理解与候选优化方法

##### 3.3.1 查询歧义检测

第一段写歧义来源：短查询可能缺少主体、对象、动作或场景约束。

第二段写选择性触发机制：不是所有查询都改写，而是根据歧义评分决定是否调用 LLM。强调该模块用于系统层优化，不是本文主创新。

##### 3.3.2 选择性查询改写

第一段写 rewrite 的目标：补充缺失语义，而不是改变原始意图。

第二段写限制：MSR-VTT 许多测试查询本身较清晰，因此 rewrite 全量启用收益有限；这一点应在第5章用 query clarity diagnosis 图解释。

##### 3.3.3 候选重排序

第一段写 rerank 的作用：在 Top-5 或 Top-10 候选内重新比较查询语义与候选视频语义。

第二段写局限：LLM rerank 成本高，且依赖候选描述质量；实验显示其没有成为最终主增益来源。

##### 3.3.4 系统型优化与表征增强的边界

第一段写结论：rewrite/rerank 用于分析系统增强上限，而 alignment teacher 与 multiview features 才是最终主方法。

第二段用一句过渡到 3.4：当系统型后处理收益有限时，更可靠的方向是提升学生模型本身的跨模态表示能力。

#### 3.4 Alignment Teacher 细粒度对齐监督

##### 3.4.1 设计动机

第一段写根源问题：全局向量能判断整体相关，但不能稳定判断“具体对象、动作、关系是否对应”。

第二段写 teacher 的作用：alignment teacher 用于提供查询语义成分与视频局部证据之间的对齐监督，而不是替代最终检索模型。

##### 3.4.2 查询语义成分分解

第一段写分解维度：action、object、scene、relation、person_attribute。

第二段写为什么这样分：这些维度对应 failure diagnosis 中最常见错误类型，能够让方法设计与误差分析形成闭环。

##### 3.4.3 视频局部证据构建

第一段写视频侧证据：从多帧、多片段中提取视觉语言特征，形成候选视频的局部语义证据。

第二段强调不做昂贵全库交叉编码：局部证据用于训练监督和候选校准，保持系统可运行性。

##### 3.4.4 教师软标签与排序偏好

第一段写 teacher 输出：对每个 query-candidate 给出软标签、局部对齐分数或候选偏好。

第二段给公式：

\[
\mathcal{L}_{teacher}=\sum_i \mathrm{KL}(P_T(q_i,V_i)\|P_S(q_i,V_i))
\]

说明教师分布用于约束学生候选排序分布。

第三段给 pairwise 约束公式：

\[
\mathcal{L}_{pair}=\max(0,m-S(q,v^+)+S(q,v^-))
\]

说明 \(v^+\) 为目标视频，\(v^-\) 为高相似但错误的 hard negative。

##### 3.4.5 Alignment Teacher 的作用分析

第一段写实验链路：alignment teacher 从 49.0 到 49.5，再到 train targets 后达到 50.0，说明局部监督逐步改善 Top-1。

第二段提示插图：此处可引用第5章主实验曲线，也可在本章放图3-4核心消融图。

#### 3.5 多视角视频特征增强

##### 3.5.1 设计动机

第一段写视频侧瓶颈：单一全局视频向量容易抹平局部动作和对象差异。

第二段写多视角思想：从不同时间窗口、帧组合和片段粒度提取补充表示，增强视频侧证据。

##### 3.5.2 多帧与多时间窗表示

第一段写具体构成：全局帧均值、局部片段视角、多时间窗视角。

第二段写公式：

\[
M(v)=\{m_1,m_2,\ldots,m_K\}
\]

其中 \(m_k\) 表示第 \(k\) 个视频视角特征。

##### 3.5.3 查询感知的视角匹配

第一段写 query-aware：当 query 包含 action/relation/person_attribute 时，提高局部视角权重；简单 scene/object query 则保持全局表示为主。

第二段给融合公式：

\[
S_{final}(q,v)=(1-\alpha_q)S_{global}(q,v)+\alpha_q S_{local}(q,v)
\]

说明 \(\alpha_q\) 与查询复杂度、候选间距和局部语义成分有关。

##### 3.5.4 多视角特征与 alignment teacher 的互补关系

第一段写互补：teacher 提供“应该对齐什么”，multiview features 提供“视频侧可供对齐的证据”。

第二段插图3-2：图名“图3-2 细粒度对齐教师与多视角特征训练流程”。插入位置：3.5.4 第二段之后。已生成：`outputs/figures/Figure3-2_alignment_multiview_training_flow.drawio`。

##### 3.5.5 多视角增强的边界

第一段写实验教训：q1500 扩大样本与 vtokens6 并未稳定超过 q500 effective222，说明多视角特征必须与高质量 near-miss 样本和合适权重共同使用。

第二段写论文表达：这是一个重要负结果，说明方法不是靠堆特征，而是靠有效局部监督和适配的训练协议。

#### 3.6 联合训练目标与消融实验设计

##### 3.6.1 总体训练目标

第一段写总损失：

\[
\mathcal{L}=\mathcal{L}_{rank}+\lambda_1\mathcal{L}_{teacher}+\lambda_2\mathcal{L}_{align}+\lambda_3\mathcal{L}_{pair}+\lambda_4\mathcal{L}_{preserve}

逐一解释每项作用。

##### 3.6.2 Hard Negative Mining

第一段写 hard negative 来源：不是随机负样本，而是当前模型排在前列但与 GT 不一致的候选。

第二段写目的：让模型学习“相似但错误”的细微差异。

##### 3.6.3 表征保持约束

第一段写 preserve：避免学生模型为了局部样本过拟合而破坏原始全局召回能力。

第二段写必要性：q1500 扩大样本实验出现 R@1 下降，说明保持约束对稳定 Top-1 很重要。

#### 3.7 错误驱动反馈学习机制

##### 3.7.1 失败样本识别

第一段写失败定义：GT 未进入 Top-1 或目标排名较低的样本。

第一段写原则：只围绕失败样本构建高价值监督，不平均学习全部样本。

第二段写筛选：优先选择 GT 已在候选内但未排首位的 near-miss 样本。
