## Research References

### ViCLIP

- Main idea used here:
  video-text representation learning should stay strong under transfer, so the
  main embedding teacher in the target design remains `ViCLIP`
- Reference:
  `ViCLIP: VideoCLIP? / simple video CLIP for transferable video-text representation`
  ICLR 2024 proceedings:
  https://proceedings.iclr.cc/paper_files/paper/2024/file/b7bfab38ed694b43e8c20c14f6c0e900-Paper-Conference.pdf
  and model page:
  https://huggingface.co/OpenGVLab/ViCLIP

### ColBERT Late Interaction

- Main idea used here:
  keep a cheap retrieval pipeline while preserving finer-grained interaction
  for reranking or teacher guidance
- Reference:
  `ColBERT: Efficient and Effective Passage Search via Contextualized Late Interaction over BERT`
  https://arxiv.org/abs/2004.12832

### Ranking Distillation

- Main idea used here:
  student ranking can learn from teacher ordering signals, not only the single
  positive label
- Reference:
  `Ranking Distillation: Learning Compact Ranking Models With High Performance for Recommender System`
  https://arxiv.org/abs/1809.07428

### Lossless / Self Distilled Neural Ranking

- Main idea used here:
  ranking distillation can be used not only for compression but also to push a
  student beyond the current point solution when teacher ordering is strong
- Reference:
  `Improving Neural Ranking via Lossless Knowledge Distillation`
  https://research.google/pubs/improving-neural-ranking-via-lossless-knowledge-distillation/

### Why Top-k30 First

- The reranker can only improve `R@1 / R@5 / R@10` if the ground-truth video is
  already inside the baseline candidate set
- The practical question is therefore not only baseline `R@1`, but also
  baseline candidate recall at `topk=30`
- The current lightweight route is:
  baseline candidate recall check on full `1kA` -> `ViCLIP` supervision on
  baseline `topk30` candidates -> light adapter distillation -> `1kA 200-query`
  quick gate

### Remaining Optimization Roadmap

- Stage 1A:
  `ViCLIP` similarity distillation on baseline `topk30` candidates with
  `teacher_topk=10`
- Stage 1B:
  add hard negatives, prototype-aware learning, and
  constraint-memory-assisted sampling on the same compact candidate set
- Stage 1C:
  tune fusion weights, adapter residual scale, and hard-negative count while
  preserving a cheap training loop
- Stage 2A:
  add `ViC-style top-20 listwise soft labels` only within already retrieved
  candidates
- Stage 2B:
  add frame relevance only to the hardest query buckets instead of all queries
- Stage 2C:
  test cheap late-interaction bonuses on hard subsets, not the whole pool
- Stage 3A:
  use memory first as a sampler for hard queries, hard negatives, and valuable
  teacher pairs
- Stage 3B:
  refresh prototype, hard-negative, and constraint memories only after
  accepted student updates
- Stage 3C:
  once quick-gate wins are stable, promote to full `1kA`, then prepare
  ablation tables, plots, diary summaries, and interface-ready artifacts

### Stage 2

- Add frame relevance teacher
- Add late interaction teacher
- Add ViC-style top-20 listwise soft labels

### Stage 3

- Refresh prototype memory
- Refresh hard negative memory
- Refresh constraint memory
- Accept only students that improve train, val, and full `1kA`
